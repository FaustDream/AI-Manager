# 组件替换清单

外部组件底座的选型结论、全站待替换站点盘点、以及逐项完成度。**每替换一处就更新这里一行**。

底座统一为 **Radix UI Primitives**，全部包在共享组件目录内对外仍是同名组件；页面不直接 import Radix。
令牌体系、`DataTable` 列定义、`zustand` + `react-query` 状态源一律不动。

## 1. 选型结论

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| **Radix Primitives 包进共享层** | 无样式基座，颜色/字号/圆角/阴影全由现有令牌承担；焦点管理、Esc、碰撞翻转、键盘漫游、`role`/`aria` 开箱即用；按需引入可 tree-shake；页面 API 不变即获得新交互 | 不含日期选择器；样式层要自己写 | **采用** |
| shadcn/ui 整套拷入 | 组件更全（Calendar / Command / Table） | 带自己的 class 约定，要重写令牌映射；与现有列定义表格 API 冲突需二选一；维护面翻倍 | 否 |
| Ant Design 5 | 表格/日期/上传/树开箱即用 | 自带主题与 ConfigProvider 状态源，与 Tailwind v4 `@theme` 正面冲突；包体 +1MB 以上；违反「不引第二套状态源」 | 否 |

已引入的包（`package.json` dependencies）：

```
@radix-ui/react-tooltip     @radix-ui/react-select      @radix-ui/react-popover
@radix-ui/react-dropdown-menu  @radix-ui/react-switch   @radix-ui/react-tabs
@radix-ui/react-dialog      @radix-ui/react-checkbox
```

实测包体代价：主 chunk 465.9 kB → 525.9 kB（gzip 149.3 kB → 169.8 kB，**+20.4 kB gzip**）。

**刻意不换的**：

- **表格**：保留自有列定义渲染（`DataTable` / `Column<R>`）。加一列 = 加一条列定义，这是全站一致的口径，换第二套表格实现会丢掉它。只把表头排序提示与单元格提示换成 Radix。
- **滚动条**：继续用全局 CSS 的 8px 主题化滚动条。Radix ScrollArea 会接管轨道与滑块，和令牌体系打架。
- **日期输入**：保留原生 `type="date"` / `datetime-local`（已主题化）。Radix 无日期选择器，不为此再引一套库。
- **Toast**：保留现有实现（zustand + motion，成功一句、失败可展开原文），行为已符合规范。

## 2. 共享层新增组件

| 组件 | 文件 | 底座 | 对外 API |
| --- | --- | --- | --- |
| `Tooltip` / `Hint` / `TooltipProvider` | `components/ui/tooltip.tsx` | react-tooltip | `content`（`\n` 自动拆行：首行结论、后续行原因）、`side` / `align` / `wide`；`Hint` 用于无交互内容，`focusable={false}` 供表格单元格避免多出 tab 停靠点 |
| `Switch` | `components/ui/switch.tsx` | react-switch | `checked` / `onCheckedChange` / `label` / `hint` / `size`。`role=switch` + `aria-checked`，取代「拿勾选框当开关」 |
| `Picker` | `components/ui/picker.tsx` | react-select | `value` / `onValueChange(string)` / `options: {value,label,disabled}[]`。**不伪造 change 事件**，迁移时把 `onChange={e => f(e.target.value)}` 换成 `onValueChange={f}` |
| `DropdownMenu` / `ContextMenu` | `components/ui/menu.tsx` | react-dropdown-menu | `entries: (MenuEntry \| 'separator')[]`，`MenuEntry` 含 icon / shortcut / danger / disabled |

`TooltipProvider` 挂在 `AppProviders` 一次，全站共用 220ms 延迟与 400ms 跳过窗口。

### 一条必须记住的底座陷阱

Radix 的 `Presence` 在关闭时读 `getComputedStyle(node).animationName`：**只要不是 `none`，它就等 `animationend` 才卸载节点**。

所以浮层内容**只挂入场动画，且必须用 `data-[state=open]:` 前缀**：

```
data-[state=open]:animate-[fade-in_var(--dur-2)_ease-out]
```

- 前缀不能省。写成无条件 `animate-[...]` 时，关闭后 animationName 依然非 none，而入场动画早已结束、不会再触发 `animationend` → **浮层永久卡在屏幕上**。
- 键名必须真实存在。全局样式表里是 `fade-in` / `fade-out`，不是 `overlay-in`（那是 class 名不是 keyframe 名）；写错键名同样会让 Presence 一直等。
- 不要补 `data-[state=closed]:animate-[fade-out...]` 来「做退场」：页面被隐藏时浏览器暂停动画，`animationend` 永不触发，又会卡住。关闭时 animationName 归 `none`，Presence 立即卸载，这也符合规范「只做出场不做退场」。

## 5. 替换一处的工作口径

1. 从 `@/components/ui` 取组件，**不深链具体文件、不直接 import Radix**。
2. 缺形态时**先扩共享组件的 props**，再在页面用；不在页面里复制一份类名。
3. 颜色/字号/间距/圆角/阴影/时长只从令牌取。
4. 图标按钮给 `aria-label`；开关用 `Switch`（`role=switch`）而不是勾选框。
5. 禁用态必须给 `hint` 说明为什么不能点。
6. 改完更新本文件对应行的状态与第 4 节计数。
7. 跑 `npx tsc --noEmit && npx vitest run && npm run build`，再实机过一遍浮层焦点/Esc/碰撞翻转与窄屏回落。
