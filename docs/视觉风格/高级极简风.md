# 高级极简风

- **键位**：`minimal`
- **明暗**：浅色
- **气质**：暖纸底色配棕色强调，留白多、配色克制。四套里圆角最小、阴影最轻，层次靠发丝线与留白建立，不靠投影——适合长时间阅读与精细排版。

| 圆角 | 小 4px / 中 6px / 卡片 8px / 大尺寸 10px，四套里最小 |

`color-scheme: light`。这套的"极简"不是去掉层次，而是把层次从投影转移到边界与留白；改这套时别靠加阴影解决问题。
