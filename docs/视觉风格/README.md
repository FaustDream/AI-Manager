# 视觉风格

本目录存放每一套视觉风格的说明，每套一份。主文档是上一级的「前端设计规范」，只讲共用机制和新增流程；具体风格的取值与气质写在这里，新增一套就加一份，不改主文档。

## 当前已登记

| 键位 | 名称 | 明暗 | 说明 |
| --- | --- | --- | --- |
| `business` | 简约商务风 | 浅色 | 浅灰画布 + 白卡 + 蓝强调，默认浅色风格 |
| `tech` | 暗色科技风 | 深色 | 深底 + 紫蓝发光 + 冷霓虹，默认深色风格 |
| `soft` | 柔和现代风 | 浅色 | 低饱紫青渐变 + 大圆角 + 紫调阴影 |
| `minimal` | 高级极简风 | 浅色 | 暖纸留白 + 棕强调 + 发丝线，几乎不投影 |

跟随系统（`''`）不写 `data-theme`，由系统深浅分别落到上表标明的默认浅色与默认深色风格。

## 每份说明写什么

新增风格时按同一结构写，便于对照：

1. 键位、名称、明暗、默认角色（是否为浅色/深色默认）。
2. 一句话气质与适用场景。
3. 关键令牌：画布与表面层次、强调色族、语义色、图表色、底纹、圆角、阴影、发光。
4. 与共用默认值的差异——只列覆盖项，不重复 `@theme` 已有值。

## 同步位置

风格要真正可用，需同时落在三处代码与一份文档：

- 全局样式表：一个 `[data-theme="<key>"]` 块，只覆盖差异键位。
- 风格注册表：一条元数据，菜单与设置页靠它自动出现。
- 页面入口：一段 `[data-splash='<key>']` 首屏配色，避免闪白。
- 本目录：一份风格说明，取值与代码逐项对齐。

旧键位迁移才动注册表的旧键映射；新风格没有旧键就不碰。
