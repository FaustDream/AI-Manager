# 柔和现代风

- **键位**：`soft`
- **明暗**：浅色
- **气质**：低饱和紫青渐变铺底，白卡浮在上面，圆角与阴影都比商务风更松。阴影带紫调，跟着环境色走，不是中性灰——这是它和简约商务风最直观的差别。

| 圆角 | 小 8px / 中 10px / 卡片 16px / 大尺寸 20px，四套里最大 |

`color-scheme: light`。阴影与环境色一致是刻意的：换成灰影会让这套风格失去"柔和"的辨识度。
