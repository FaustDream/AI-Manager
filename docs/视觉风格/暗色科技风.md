# 暗色科技风

- **键位**：`tech`
- **明暗**：深色，默认深色风格
- **气质**：近黑蓝底，紫蓝强调配青色点缀，唯一带发光的一套。冷霓虹底纹透明度略高，用于叙事页背景；表格页靠令牌压低，不喧宾夺主。
