# 前端设计规范

方向：**一套键位、可插拔风格、两种密度**。所有页面用同一批组件拼出来，视觉差异只由令牌值承担。当前已登记的风格见「视觉风格」文件夹；新增风格只补一份风格说明，不随风格数量改本文档。

三条硬约束，改任何页面前先记住：

1. 颜色 / 字号 / 间距 / 圆角 / 阴影 / 时长**只从令牌取**，组件里不写死色值、不手写 `150ms` 这类魔数。
2. 重复出现的界面**一律用共享组件库的组件组合**，不在页面里另写一套样式。
3. 叙事页放宽、表格页紧凑，**由 `manifest.fluid` 分流**，不靠逐页调 padding。

---

## 1. 视觉方向：风格可插拔，一套键位

风格共用同一批键位，换肤只换值、不换结构。风格的真源是全局样式表，每套风格的取值与气质单独记在「视觉风格」文件夹的分篇里；主文档不列清单，新增风格不必改这里。

- **跟随系统**（`''`）不写 `data-theme`：由系统浅色/深色分别落到当前注册的浅色默认与深色默认风格；这两套默认由风格注册表的明暗标记区分，不写死键名。
- 切换入口两处，共用同一份选择快照：顶栏风格菜单、设置 → 常规 → 外观。菜单项直接遍历注册表，新增风格自动出现。
- 风格真源是后端 kv `ui.theme`；导航布局与字号是纯显示偏好，落本地存储（导航与字号各一个键）。
- 首屏配色提示只是**绘制提示**，给页面入口的内联脚本用，避免暗色用户先被闪一屏白。丢了不影响真正的选择。
- 发光键位（`--glow-accent` / `--glow-ring`）只有暗色风格给值，其余是 `none`——组件照常引用，不用判断主题。

## 2. 页面骨架

```
┌─────────────────────────────────────────────────────────┐
│ Navbar  折叠开关 · 搜索(Ctrl K) · 返回 · 刷新 · 风格 · 退出 │  固定，不随滚动跑
├──────────┬──────────────────────────────────────────────┤
│ Sidebar  │ Main                                         │
│ 分组导航  │  PageHeader   标题 + 一句话定位 + 页面动作     │
│ 快捷键    │  关键数据      数字瓦片 / 结论卡              │
│ 本机状态  │  图表 / 表格   证据与明细                     │
│          │  动作区        批量操作 / 导入 / 导出          │
└──────────┴──────────────────────────────────────────────┘
   浮层：Dialog · Drawer · Confirm · Toast · CommandPalette
```

### 三种导航布局（设置 → 外观可切，界面状态模块定义）

| 键位 | 形态 | 适用 |
| --- | --- | --- |
| `sidebar` | 240px 分组侧栏 + 细顶栏，可折叠成图标态 | 页面多时最好找，默认 |
| `topbar` | 顶栏一排标签，无侧栏 | 窗口矮时最省纵向空间 |
| `rail` | 56px 常驻图标轨道，可展开 | 表格要横向空间时用 |

三种布局**共用同一棵组件树**，只改宽度与文字显隐；折叠不换组件、不重挂页面。

### 两种密度（`manifest.fluid`）

| 类型 | `fluid` | 容器 | 页面 |
| --- | --- | --- | --- |
| 叙事页 | 不给 | `max-w-1440` 居中，`px-6 pt-5 pb-8` | 仪表盘、设置 |
| 表格页 | `true` | 吃满宽度，`px-4 py-3` | 账号中心、会话、技能 MCP、接口反代、日志 |

表格页保持紧凑是**有意的例外**：列多、行多，一屏能扫到的行数比留白重要。

### 浮层选型

| 组件 | 用在 | 判据 |
| --- | --- | --- |
| `Dialog` | 表单、确认、说明 | 内容有限高，一屏读完 |
| `Drawer` | 日志上下文、长流内容 | 需要整个视口高度，避免嵌套两层滚动 |
| `confirmAction` | 破坏性动作 | 必须二次确认，文案说清后果 |
| `toast` | 动作结果 | 不打断操作；失败可展开原文 |
| `CommandPalette` | 跳转 / 触发已有命令 | 不发明新能力 |

## 3. 设计令牌（全局样式表）

`@theme` 里定义共用默认值，每个 `[data-theme]` 块只覆盖该风格与默认值不同的项，数量随注册风格增减。

| 类别 | 键位 | 说明 |
| --- | --- | --- |
| 中性层 | `canvas` / `bg` / `card` / `sunken` / `hover` / `scrim` | 画布 → 表面 → 抬升面 → 内凹井，四层分开，深色下才有层次 |
| 文字 | `fg` / `fg2` / `muted` | 正文 / 次要 / 辅助 |
| 边界 | `line` / `line-strong` | 轻边框；强边界只给分隔与滚动条 |
| 主色族 | `accent` / `accent-strong` / `accent-soft` / `on-accent` | 选中态、主按钮、链接、图表主系列 |
| 副色 | `iris` / `info` / `magenta` | 借给边框、图标、渐变、发光 |
| 语义 | `ok` / `warn` / `bad` / `bad-strong` + 各自 `-soft` | 状态文字用本色，整行底色用 `-soft` |
| 图表 | `--chart-1..8` | 色相 + 明度双重拉开，配直接标签 |
| 底纹 | `--mesh-1..3` / `--mesh-alpha` | 三处不同色相的径向渐变；表格页透明度压低 |
| 间距 | `--space-1..8` | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64，8px 为主档 |
| 圆角 | `sm 6` / `md 8` / `lg 12` / `xl 16` | 卡片走 `lg`，各风格微调 |
| 阴影 | `card` / `card-hover` / `pop` / `sticky-edge` | 轻边框 + 低透明度，静置一档、悬浮一档、浮层一档 |
| 动效 | `--dur-1..4` / `--ease-out` / `--ease-std` | 120 / 180 / 240 / 400ms |

**字阶**（`[data-font="large"]` 每档 +1px，只覆盖令牌，组件类名不动）：

| 类名 | 标准 | 用途 |
| --- | --- | --- |
| `text-xs` | 12px | 辅助、表头、徽标 |
| `text-sm` | 13px | 表格正文、次要说明 |
| `text-md` | 14px | 正文基准（`body`） |
| `text-lg` | 16px | 小标题 |
| `text-xl` | 20px | 数字瓦片 |
| `text-2xl` | 24px | 页面标题 |
| `text-3xl` | 28px | 首屏大数 |

## 4. 组件库（共享组件目录）

| 组件 | 职责 | 边界 |
| --- | --- | --- |
| `Button` | 五种变体 `default / primary / soft / ghost / danger`，三档 `sm / md / lg`，内建 loading | 页面不自己写按钮底色 |
| `Card` / `Section` / `PageHeader` | 版式容器：卡片、分区头、页头 | 只管容器与标题层级，不管业务 |
| `Tag` / `Notice` | 状态标签 / 整条提示 | 语义色只从这里出 |
| `Input` / `Select` / `Textarea` / `Checkbox` / `Field` | 表单控件与字段包装 | 含 focus / disabled / 错误态 |
| `StateBlock` | 空态与错误态：图标 + 短结论 + 解释 + 下一步 | 标题一句话，解释进 `detail` |
| `SkeletonBlock` / `SkeletonRows` | 加载占位 | 形状照抄真实内容，避免加载完跳版 |
| `DataTable` / `LoadMore` | 列定义驱动的表格：三态排序、sticky 表头、前置/操作列、行键盘可达、紧凑档 | 加一列 = 加一条列定义 |
| `Dialog` / `Drawer` / `confirmAction` | 浮层与确认 | 焦点管理、Esc、遮罩统一 |
| `toast` / `ToastHost` | 动作反馈 | 成功一句、失败可展开 |
| 图标注册模块 | 动作图标注册表 | 列定义只存图标名，换库不改页面 |

使用规则：

- 页面从共享组件目录的统一出口取组件，不深链具体文件。
- 需要新形态时**先扩组件的 props**，再在页面用；不要在页面里复制一份类名。
- 表格页面统一形态：带边界的工具条卡（首行 `bg-sunken`）+ 带边界的表格卡（表头 `bg-sunken` 铺满卡宽）。

## 5. 细则

一句话一条，实际开发按现场微调，不必逐条对齐像素。

- **图标**：只用 `lucide-react`（ISC，免费）。不混第二套网格/笔画，不用 `▲▼✓→` 这类字符当图标。
- **状态**：Hover / Focus / Loading / Disabled / Success / Error 六态都要有；禁用态给 `title` 说明为什么不能点。
- **动效**：状态色 `--dur-1`，入场 `--dur-2`，内容节奏 `--dur-3`，进度 `--dur-4`；只做出场不做退场，`prefers-reduced-motion` 一律降级。
- **切页**：空闲预热 chunk → `await cap.load()` → `startTransition`，全程不白屏、不退回骨架。
- **滚动条**：全站 8px，轨道透明、滑块 `line-strong`、悬停混入 `accent`，不用浏览器默认样式。
- **焦点**：全局 `:focus-visible` 一条规则，2px `accent` 环；鼠标点击不出环。
- **空/错态**：结论短、解释另起、给下一步动作（重试 / 清空筛选 / 重新扫描）。默认时间窗造成的空要说清「不是丢了，是被窗口挡住了」。
- **无障碍**：图标按钮必须有 `aria-label`；切换用 `aria-pressed` / `aria-selected`；折叠用 `aria-expanded`；装饰元素 `aria-hidden`。
- **图表**：Canvas 读不到 CSS 变量，用 `useChartPalette` + `onThemeChange` 重绘；系列色取 `--chart-1..8`，配直接标签而不只靠颜色。
- **底纹**：叙事页可用极光/网格光，外层必须 `overflow-hidden` 裁切，否则给 `main` 撑出横向滚动条。

## 6. 开发流程与优先级

需求分析 → 信息架构 → 视觉风格 → 令牌与组件 → 页面布局 → 组件开发 → 接数据与交互 → 响应式 → 测试与视觉优化。

单页打磨顺序：**布局 → 层级 → 颜色 → 间距 → 字体 → 细节**。前一层没定就别调后一层。

技术栈（已落地，不引入第二套状态源）：React 19 + TypeScript + Vite 6 + Tailwind v4 `@theme` + `@tanstack/react-query` + `zustand` + `motion/react` + `echarts`（按需注册）+ `lucide-react`。

### 新增一个页面

1. 建一个能力目录，写清单文件（`id / title / icon / order / group`，表格页加 `fluid: true`）。清单由框架自动注册路由与导航。
2. 写页面入口文件，从共享组件目录取组件拼版式。
3. 数据走 `queryCmd` + `react-query`，加载/空/错三态用 `SkeletonXxx` 与 `StateBlock`。
4. 导航、路由、命令面板、快捷键**自动生成**，核心代码零改动。

### 新增一套风格

1. 在「视觉风格」文件夹建一份该风格的说明，写清画布、强调色、气质、圆角与关键令牌差异。
2. 在全局样式表加一个 `[data-theme="<key>"]` 块，只覆盖差异键位，取值与说明文档对齐。
3. 在风格注册表加一条（`key / name / note / swatch / dark`），菜单与设置页自动出现新风格。
4. 在页面入口加一段 `[data-splash='<key>']` 首屏配色。组件一行都不用改。
5. 若是旧键位迁移，在注册表的旧键映射处补一条；没有旧键就不动。

### 提交前验收

```bash
npx tsc --noEmit && npx vitest run && npm run build
```

界面另需实机过一遍：风格注册表中全部风格 × 三布局 × 全部页面，看渲染、控制台、主流程、横向溢出/裁切/遮挡，以及窄屏（1280 / 1024 / 900 / 430）回落与反复切页的稳定性。新增风格后按同一口径回归。
